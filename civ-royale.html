Civ Royale is a mobile 4X strategy game where players build civilizations, expand territory, manage resources, and compete against other players. The game adapts the 4X genre for shorter mobile sessions while maintaining strategic depth.

My contributions

As Game Designer, I worked across systems, level design, and economy.

  • Designed and documented core mechanics and support systems
  • Executed level design directly in Unity, creating maps for varied strategic experiences
  • Designed Season Pass structure, progression pacing, and reward composition
  • Created general economy systems including currency flow, sink/source balance, and monetization touchpoints
  • Conceptualized UI revamp and created mockups in collaboration with the art team

The context

Civ Royale was my first role focused purely on game design, and it was on a genre I genuinely love. I've been playing strategy games since Age of Empires and Civilization, so working on a 4X felt like a natural fit.

I started as a part-time designer, but after a few months I was offered the main game designer position on the project. The core challenge was translating the 4X feeling into a quick, free-to-play mobile experience. That meant lots of iteration on the main mechanics, finding the right balance between strategic depth and session length.

It was a small team, so I wore many hats. Beyond systems and level design, I did hands-on implementation in Unity and took ownership of UI design. This is where I developed my Figma skills, creating mockups for menus, sales screens, pop-ups, tutorials, and anything else the game needed.
